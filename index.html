Anotar partitura

Arraste um PDF de partitura e baixe de volta o mesmo PDF com o nome de cada nota escrito embaixo da pauta. Nada é re-desenhado — só entra uma camada de texto. Roda inteiro no seu navegador: o arquivo não sai do seu computador.

🎼 Arraste os PDFs aqui ou clique para escolher pode soltar vários de uma vez
Nomes

Funciona com partitura gerada por computador (MuseScore, Dorico, Sibelius, Finale). PDF escaneado não dá — sem vetor não há coordenada para ler a altura das notas.

Leitura por geometria vetorial, não OCR: as cabeças de nota já estão no PDF como caracteres de fonte musical, então a altura sai por aritmética sobre as coordenadas. Código no GitHub.
